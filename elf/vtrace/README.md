# VTrace

В этой задаче нужно написать библиотеку `libvtrace.so` для трассировки вызовов внешних функций. Она должна запускаться через `LD_PRELOAD` и печатать в `stdout` имена функций из внешних библиотек.

Пример работы библиотеки:

```c
#include <stdio.h>

int main() {
    puts("Hello, world!");
    return 0;
}
```

```console
$ LD_PRELOAD=./libvtrace.so ./tests/hello-world/hello-world
[puts]
Hello, world!
```

* LD_PRELOAD — это переменная окружения, которая указывает, динамическому линковщику, какие библиотеки должны быть дополнительно загружены перед запуском программы, помимо тех, которые были явно указаны при сборке. В неё могут быть указаны несколько библиотек, разделенных двоеточием.

Общая идея решения заключается в том, чтобы перед запуском программы найти все внешние функции (то есть те, которые находятся в GOT), и подменить их на свои тонкие обёртки, которые будут сначала печатать имя функции, а потом вызывать оригинальную реализацию.

Некоторые детали:

- На каждый вызов внешней функции должна печататься строка вида `[имя_функции]`. Строка должна печататься до вызова самой функции;
- Трассироваться должны только вызовы функций, совершаемые непосредственно из исполняемого файла. Вызовы функций из внешних библиотек не должны трассироваться;
- Одна и та же функция может вызываться много раз, каждый из них необходимо трассировать;
- Не нужно трассировать функции, относящиеся к процессам внутри рантайма или санитайзерам. Если название функции начинается с символа нижнего подчеркивания `_`, то её необходимо игнорировать при трассировке;

Возможно несколько путей решения задачи, но, скорее всего, в процессе решения вам потребуется найти ответы на следующие вопросы:

- Как найти список функций из GOT? Как из этого списка получить адрес в GOT, отвечающей этой функции? Как получить строку с именем функции?
- GOT содержит указатель на функцию. Как должен выглядеть указатель для функции-обёртки? Очевидно, что это должны быть разные указатели; правда ли, что обёртка для каждой функции должна отличаться от других? Можно ли вынести общую часть обёртки в отдельную функцию, а раздельной иметь только уникальную для каждой функции часть? Как динамически генерировать обёртку для каждой функции?
- Для того, чтобы напечатать что-то из хендлера, необходимо вызвать внешнюю функцию, которая напечатает что-то на экран. Как избежать бесконечной рекурсии?
- Если программа собирается с `partial RELRO`, то в GOT лежит адрес хендлера в PLT, который при первом вызове перепишет ваши модификации в GOT. Как этого избежать?
- Если программа собирается с `full RELRO`, то GOT изначально read-only. Как обойти это ограничение?
